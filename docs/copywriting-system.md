# Nura Skin — Copywriting System

## Core Voice Principles

1. **Darija-first**: Write as a knowledgeable Moroccan friend, not a translation
2. **Calm confidence**: Never shout, never desperate, never pushy
3. **Specific over vague**: "10% ناياسيناميد" not "تركيبة قوية"
4. **Problem-aware**: Lead with what the customer feels
5. **Claim-safe**: Cosmetic language only, no medical promises
6. **Premium economy**: Few words, high impact

---

## Language Structure

### Primary: Arabic Darija
All body copy, product descriptions, CTAs, checkout flow, and customer-facing communication.

**Darija markers to use:**
- "واش" (do you / is it) — opening questions
- "بزاف" (a lot / very) — natural intensifier
- "دابا" (now) — immediacy
- "مزيان" (good/nice) — quality affirmation
- "كاين/كاينة" (there is) — existence statements
- "تقدري" (you can) — empowerment
- "راني" (I am) — first person informal
- "بغيتي" (you want/wanted) — desire language

### Secondary: French (Selective)
Used only for:
- Product names (Nura Balance, Nura Night Renewal, Nura Eye Revive)
- Ingredient INCI names
- Occasional prestige signal in premium contexts

Never: full French sentences in Arabic copy blocks.

## Copy Templates by Section

### Hero Headline (Home)
Format: **[Emotional insight about Moroccan skin] — [Promise]**

Example:
> "بشرتك تستاهل عناية تفهمها — مصنوعة للمرأة المغربية"

### Product Hero Headline
Format: **[Problem in Darija] → [Solution mechanism]**

Example (Balance):
> "البشرة اللامعة، المسام الواسعة — مركّز نيورا بالانس يساعد على إعادة التوازن"

### Ingredient Section Title
> "شنو كاين فـ [اسم المنتج]؟"

### Ingredient Card
Format: **[Arabic name] — [INCI name]**  
**[What it does in one claim-safe sentence in Darija]**

### Social Proof
Format: **[Real name], [City] — [Specific outcome in Darija]**

Example:
> "مريم، الدار البيضاء — ولدت ناعسة وبشرتي ولات أنعم بكثير بعد أسبوعين"

### CTA Hierarchy
| Priority | CTA Text | Context |
|---|---|---|
| Primary | "أضيفي للسلة" | Product page, hero |
| Secondary | "اطلبي الآن" | Bundle offers |
| Cart | "أكملي طلبك" | Cart drawer |
| Checkout | "أكّدي طلبك" | Checkout popup |
| Upsell accept | "نعم، أضيفيها لطلبي" | Upsell modal |
| Upsell decline | "لا شكراً" | Upsell modal |

### COD Badge Text
> "الدفع عند الاستلام — ما تدفعي حتى يوصلك الطلب"

### Scarcity (Real Only)
> "بقا غير [X] قطعة — احجزي طلبك قبل ما ينتهي"

### FAQ Format
**Q:** "[Question as customer would ask it in Darija]"  
**A:** "[Answer that resolves objection, calm and informative]"

## Claim Safety Quick Reference

| Say This | Not This |
|---|---|
| "يساعد على تخفيف مظهر الهالات" | "يزيل الهالات" |
| "يساعد على توحيد مظهر البشرة" | "يعالج عدم التوحيد" |
| "بشرة تبدو أكثر نعومة" | "يجعل البشرة ناعمة بضمان" |
| "مكونات مدروسة علمياً" | "مثبت علمياً" |
| "تركيبة بتركيز X%" | "أقوى تركيز في المغرب" |
| "يساعد على تقليل مظهر المسام" | "يضيّق المسام" |
